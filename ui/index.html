命名配置

一个配置 = 一套「文件名模板 + 目录模板 + 日期格式 + 冲突策略」，可绑定到平台或任务
任务里"跟随全局"时使用其平台对应的配置；任务里自定义过则优先用任务自己的。渲染顺序永远是：变量替换 → 非法字符处理 → 去首尾空格与点 → 截断 → 重名去重 → 拼接扩展名。

文件名模板

点击下方变量即可插入到光标处
不含扩展名；扩展名由「封装格式」自动决定（.ts / .mp4 / .m4a / .flv）
相对「存储根目录」，留空表示全部平铺到根目录；支持 / 创建多级子目录
字符，超出时截断并在结尾保留序号（Linux 单层目录名上限 255 字节，中文按 UTF-8 约 3 字节/字，故 120 字符更保险）
